# Project Overview

- **Name:** Operations Dashboard
- **Description:** A responsive, mobile-first business dashboard that explains performance through three blocks: outcome KPIs, contributing drivers, and operational details. The dashboard will cover volume, revenue, engagement, retention, performance, satisfaction, and efficiency, then expose platform, product, campaign, and alert details.
- **Tech Stack:** HTML5, Tailwind CSS CDN, vanilla JavaScript (data rendering), Flask (dev server), Python 3
- **Repo Origin:** Pivoted from `4GeeksAcademy/html-hello` starter template and the Aria Keystone landing page.
- **Difficulty:** Beginner — educational dashboard project
- **Status:** In progress. Dashboard blueprint documented; implementation not started.
